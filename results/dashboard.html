Key Findings

  • Agentic GraphRAG outperforms all other approaches by 9-25 percentage points
  • Agentic planning with entity linking, temporal resolution, and evidence evaluation improves accuracy
  • Simple GraphRAG without agentic reasoning performs worst (36.9%)
  • RAG with structured data extraction performs reasonably (52.9%)
  • LLM-Only baseline is 44.6%

Architecture

The Agentic GraphRAG system uses a plan-execute-evaluate-replan loop with:

  • Entity linking to extract and link entities to graph
  • Temporal reference resolution ("held immediately before 2016" -> 2012)
  • Type-aware action sequences (temporal, aggregation, superlative, etc.)
  • Evidence prioritization in synthesis
  • Iterative evidence sufficiency evaluation
